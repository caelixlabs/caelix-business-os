# industry/

Reserved for industry-specific configuration packs (gym, music-Org,
salon, clinic, restaurant, school) that compose `business/` and
`capabilities/` modules into an industry's default setup — the
"configurable Business OS" part of the PRD. Each pack is expected to be
mostly configuration/seed-data (which capabilities are enabled, default
roles, default fields) rather than new domain logic, since the PRD's
core requirement is that the architecture supports new industries
without redesign.

Not yet implemented.
