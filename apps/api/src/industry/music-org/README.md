# Music Org (Music Org / Music Institute)

Customer-facing industry foundation for music schools, academies, institutes and studios.

## V1 implemented slice
- Students + guardian/contact information
- Courses
- Batches with branch and teacher assignment
- Student enrollments with fee/discount capture
- Attendance
- Practice logs with teacher feedback/rating
- Operational dashboard metrics

## Intentionally deferred
- Invoicing/payment collection
- Parent/student portal
- Online classes
- CRM/lead funnel
- Marketing/campaigns
- Exams/certificates
- Instrument inventory
- Payroll/teacher commissions
- Advanced timetable/room scheduling
- Messaging integrations
- Advanced analytics

The technical namespace remains `music-Org`; the product language can use **Music Org** for music academies/institutes/studios.
